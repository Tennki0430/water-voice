# 特定商取引法に基づく表記

> ⚠️ これはテンプレートです。日本国内で有料販売する場合、本表記は **法律上の義務** です。
> `【...】` を実際の情報に置き換えてください。住所・氏名・電話番号は原則開示が必要ですが、
> 個人事業主の場合は「請求があれば遅滞なく開示する」運用が認められるケースもあります。
> 利用する決済プラットフォーム（Lemon Squeezy / Paddle 等）の要件も併せて確認してください。

| 項目 | 内容 |
|---|---|
| 販売事業者名 | 【氏名 または 屋号・法人名】 |
| 運営責任者 | 【氏名】 |
| 所在地 | 【住所】（請求に応じて遅滞なく開示します） |
| 電話番号 | 【電話番号】（請求に応じて遅滞なく開示します） |
| メールアドレス | 【メールアドレス】 |
| 販売URL | 【販売ページのURL】 |
| 販売価格 | 各商品ページに表示する価格（消費税込み） |
| 商品代金以外の必要料金 | インターネット接続料金等は利用者の負担 |
| 支払方法 | クレジットカード等（決済事業者: 【Lemon Squeezy / Paddle 等】） |
| 支払時期 | 購入手続き完了時 |
| 商品の引渡し時期 | 決済完了後ただちにライセンスキーを発行・ダウンロード提供 |
| 返品・キャンセル（返金ポリシー） | 【例: デジタル商品の性質上、原則として購入後の返金は不可。ただし重大な不具合がある場合は購入後◯日以内に申し出れば返金対応。】 |
| 動作環境 | macOS 14 以降 / Apple Silicon 推奨。購入前に体験版での確認を推奨。 |
